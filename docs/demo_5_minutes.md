# La démo en 5 minutes

**Le message :** au même endroit, une équipe nettoie, analyse, visualise et gouverne ses données, avec ou sans code.

## Avant (15 minutes avant)
- Lancer `08`, `10` et `11` (**Run all**) : les résultats restent affichés.
- Construire `HR nettoyage` dans Designer la veille, et l'ouvrir dans un onglet.
- Ouvrir 4 onglets, dans l'ordre : dashboard, Designer, notebook 08, Catalog › `hr_employee`.
- Afficher le dashboard une fois : le warehouse démarre.

## Le déroulé

| Temps | Onglet | Faire | Dire |
|---|---|---|---|
| 0:00 | Dashboard | Filtrer sur **2 projets** | « Un employé sur quatre est parti. Avec 2 projets, c'est deux sur trois. » |
| 1:00 | Designer | Montrer les boîtes, cliquer sur **Prepare** | « Comme Power Query : on relie, on clique, chaque étape reste visible. » |
| 2:15 | Notebook 08 | Lancer la cellule SQL de l'étape 5 | « Pour aller plus loin, SQL ou Python, avec les explications à côté. » |
| 3:15 | Notebook 10 | Montrer la comparaison des départements | « Cette jointure marche sans erreur, et tous les départements sont faux. Un outil facile ne suffit pas. » |
| 4:00 | Catalog | Descriptions, puis **Lineage** | « Le catalogue dit ce que veulent dire les données, qui y accède et d'où elles viennent. » |
| 4:40 | GitHub | Montrer l'adresse ou un QR code | « Compte gratuit, clonez, **Run all** : à vous. » |

## Si ça bloque
Ne pas attendre un démarrage : passer à l'onglet suivant, les résultats y sont déjà. S'il ne reste que deux minutes : dashboard, puis GitHub.
